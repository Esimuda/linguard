Linguard

Guarding language. Small models refuse scams in English and help with them in Hausa. Linguard finds that gap and closes it.

Pipeline: red-team seeds (EN · Pidgin · Yoruba · Hausa · Igbo) → AuditKIT baseline → CuratorKIT repair set → SafeTune CAA steering → LoRA weight harden → AuditKIT compare. Model: CohereLabs/tiny-aya-earth.
